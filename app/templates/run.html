Reporting a run

Your harness posts its own numbers. There is no form for this on purpose: the measurements should come from code you wrote, not from you typing them in. Save this as harness.py in the project root, put your real retrieval in it, and run .venv/bin/python harness.py. 

import httpx
from app.metrics import recall_at_k

# Replace these two with what your system actually returned, and
# what should have come back.
retrieved = ["doc-7", "doc-2", "doc-9"]
relevant = {"doc-2", "doc-4"}

httpx.post(
    "http://127.0.0.1:8765/cycles/{{ cycle.id }}/runs",
    json={
        "notes": "say how you measured, in your own words",
        "measurements": {
            "recall_at_5": recall_at_k(retrieved, relevant, k=5),
        },
    },
).raise_for_status()

The route answers 409 until you seal this cycle, and again once you score it. The route answers 422 for a measurement that is not a finite number. A harness that cannot produce a number has measured nothing.
